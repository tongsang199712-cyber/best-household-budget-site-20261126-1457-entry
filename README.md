HearthLedger — a household budget site for the fictional Alvarez family (two adults, two kids, November 2026). A dashboard with income vs spending, a spending donut and a six-month trend; a transaction ledger you can add to, filter and search; per-category budgets you can edit; bills and subscriptions with paid toggles; savings goals you can contribute to; and reports with top merchants and plain-language insights. All figures are invented demo data, everything runs offline in the browser, and edits are saved on the device only. Works on desktop and on a phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Or serve `app/` with any static file server.
